Prefer the terminal?

In this project directory, run npm run setup once, then npm run render. The CLI saves scene.mp4 and its manifest in this directory.

For another export, use npm run render -- --output second.mp4. Existing files are never replaced.

Standalone local tool. No account, API key, project connection or cloud upload.
